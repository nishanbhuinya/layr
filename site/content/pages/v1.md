# LAYR v1

LAYR began as `@dynshift/layr` 1.x: a set of React components modelled on Flutter's layout widgets. LAYR 3 is a different thing: a compiled language with its own layout model, Design Scale and Export, Extract and Inject.

## Keep using v1

v1 stays installable and maintained for fixes:

```bash
npm install @dynshift/layr@v1
```

Its source and README live on the `v1` branch of [the repository](https://github.com/nishanbhuinya/layr/tree/v1).

## Moving to LAYR 3

The two can live side by side while you move: LAYR 3 compiles to React components, so a v1 app can import `.layr` files one screen at a time. The [migration guide](/docs/migrating-from-v1) maps each v1 component to its LAYR 3 widget.

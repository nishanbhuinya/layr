# Changelog

All notable changes to Layr will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-12-22

### Added

- Initial release of `@dynshift/layr`
- Core components: `Container`, `Column`, `Row`, `Stack`, `Positioned`, `PositionedFill`, `SizedBox`, `Padding`, `Centre`
- Full TypeScript support with comprehensive JSDoc
- ESM + CJS dual build
- Zero dependencies (React peer only)
- Smoke test coverage

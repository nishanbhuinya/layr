# Code of Conduct

LAYR follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). This page is a short summary; the Covenant is the full text.

## In short

- Be kind, patient and specific. Critique code and ideas, never people.
- Welcome newcomers. Everyone was new to LAYR once.
- No harassment, insults, discrimination, sexualised content, or publishing anyone's private information.
- Assume good faith, and accept a maintainer's decision on a disagreement once it is explained.

This applies in the repository, its issues, pull requests and discussions, and anywhere you represent the project.

## Reporting

Report anything that breaks this code privately to the maintainer, [@nishanbhuinya](https://github.com/nishanbhuinya), using the contact details on that GitHub profile. Reports are kept confidential.

Maintainers may edit or remove contributions, and warn, suspend or ban people, following the Covenant's enforcement guidelines.
